# TagNotes

TagNotes is an offline note-taking app built with Flutter and Material 3.
Notes can be tagged with colored tags, searched by title, body, or tag name,
and filtered by one or more tags; notes are edited in a full-screen editor with
swipe-to-delete and a delete confirmation. All data lives in memory, so notes
reset when the app closes.

Run it with `flutter pub get && flutter run`, or `flutter test` for the smoke test.
